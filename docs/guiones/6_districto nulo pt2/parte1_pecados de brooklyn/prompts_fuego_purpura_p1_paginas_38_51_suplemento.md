# SUPLEMENTO DE PROMPTS GRÁFICOS — FUEGO PÚRPURA P1
## Páginas nuevas 38–51 — versión con lenguaje de viñetas agresivo

Este suplemento está pensado para pegar al final de `prompts_fuego_purpura_p1.md`.

## Ajuste de lenguaje visual para las referencias nuevas
- Usar **fondos blancos puros** solo en golpes rápidos, disparos quirúrgicos, llaves de combate y micro-impactos. Sirven para congelar velocidad sin sobrecargar fondos.
- Usar **siluetas negras o casi negras** para violencia visceral sugerida, impactos contra soldados, escenas turbias del under y momentos que la IA podría bloquear si se muestran de forma demasiado explícita.
- Usar **panel bleeding fuerte**: cuerpos, vehículos, humo, redes, armas y energía saliendo de viñetas.
- Usar **inset panels superpuestos** para detalles críticos: mano en palanca, comunicador, teléfono de Ian, reflejo de Norman.
- Mantener todo **sin gore explícito, sin desmembramientos, sin desnudez explícita**. Que se sienta adulto por composición, sombra y tensión, no por ponerle modo morgue a la página como edgy de secundaria.
